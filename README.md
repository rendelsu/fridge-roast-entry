A single original one-line roast of a smart fridge, written to `/output/entry.txt` by `main.ts`. The line roasts the fridge's judgemental touchscreen: it films your 2 a.m. snacks in 4K, suggests a salad, and hides your cake behind the kale.

## Run it

```sh
node main.ts
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`), creates it if needed, and writes the roast to `entry.txt` (one line, 133 characters).
